## النطاق المعتمد

اعتمد مالك المشروع الخيار الثاني: استبدال تاريخ المستودع السابق بسجل جديد يحتوي النسخة الحالية من المشروع فقط. لا يغير هذا الإجراء ملفات التطبيق العاملة أو البيانات التشغيلية؛ إنما يستبدل تاريخ Git للفرع الرئيسي في GitHub.

## الحماية قبل الاستبدال

قبل التنفيذ، أُنشئ فرع احتياطي محلي باسم `backup/pre-history-rebuild-20260814T212331Z` وحزمة Git مكتملة في المسار `/home/ubuntu/diyuni-budget-pro-history-20260814T212331Z.bundle`. تحقق فحص الحزمة من أن التاريخ كان كاملاً وقابلاً للاسترداد محلياً عند الحاجة.

## النتيجة المتحققة

أُنشئ سجل Git جديد من النسخة الحالية فقط، ثم استُبدل الفرع `github/main` بدفع قسري محدود بالمرجع البعيد المتوقع. أصبح رأس الفرع المحلي والبعيد هو الالتزام `1eb96db500bf1c5b999edf38b94e28295967d01b`، ويحتوي سجل `main` الجديد على **التزام واحد** عند وقت التحقق.

> لا يوجد تاريخ الالتزامات السابق على `github/main` بعد الاستبدال. يبقى مرجع الاسترداد المذكور محلياً في بيئة العمل الحالية فقط.
