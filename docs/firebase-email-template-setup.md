# إعداد قالب رسالة تحقق البريد في Firebase

## حالة الوصول

تم فتح Firebase Console عبر جلسة المستخدم المرتبطة بحساب Google. المشروع المستهدف ظاهر باسم **Pos mohsp** ومعرّفه `gen-lang-client-0759922046`، وهو نفس المشروع المستخدم من التطبيق. لا يوجد تكامل Firebase مخصص ضمن إعدادات الجلسة، ولذلك سيتم تطبيق إعدادات القالب من Firebase Console بعد التحقق من بيانات القالب ومسار الإجراء.

## هدف الإعداد

يجب أن يظهر اسم المنتج **ديوني وميزانيتي برو** بوضوح في رسالة تأكيد البريد، مع شعار رسمي ورابط استمرار يعيد المستخدم إلى موقع التطبيق بعد التحقق. تُسجل قيمة قالب Firebase الفعلية وبيانات الرابط النهائي في هذا المستند بعد الحفظ.

## مراجعة قالب Firebase الحالي

يوفر محرر قالب **Email address verification** حقول اسم المرسل، عنوان الرد، الموضوع، نص HTML، ورابط الإجراء. القالب الحالي باللغة الإنجليزية، باسم مرسل غير محدد، وموضوعه الافتراضي `Verify your email for %APP_NAME%`، بينما يعتمد رابط الإجراء الافتراضي على نطاق Firebase.

لن يُحفظ أي تغيير في Firebase قبل تأكيد المستخدم على المحتوى النهائي؛ لأن حفظه يغيّر الرسائل المرسلة فعلياً إلى مستخدمي التطبيق.

## المحتوى المعتمد للحفظ

أكد المستخدم الحفظ. يُضبط اسم المرسل إلى **ديوني وميزانيتي برو**، والموضوع إلى **«أكّد بريدك الإلكتروني للبدء في ديوني وميزانيتي برو»**. يستخدم نص HTML قالباً عربياً باتجاه RTL يتضمن شعار التطبيق من الرابط التالي، واسم المنتج، ووصفاً موجزاً، وزر «تأكيد البريد الإلكتروني» المرتبط بالمتغير `%LINK%`، وتنبيهاً أمنياً بعدم مشاركة الرابط:

`https://files.manuscdn.com/user_upload_by_module/web_dev_logo/310519663185110739/DbFlRYKyYiYWKMdp.png`

يُترك عنوان الرد ونطاق المرسل كما هما؛ فلا يوجد عنوان دعم أو نطاق بريد مخصص قدّمه المستخدم في هذه المهمة.

## نتيجة محاولة الحفظ

بعد تأكيد المستخدم، أُدخلت القيم في محرر Firebase وضُغط زر الحفظ. رفضت منصة Firebase التحديث ولم تُطبّق أي من التعديلات، وأظهرت الرسالة التالية: **“Email template updates are currently unavailable for this project. For assistance with template changes, contact Firebase Support.”** كما عادت الحقول إلى القالب الافتراضي، ولذلك لم يتغير البريد المرسل للمستخدمين. يلزم رفع طلب إلى دعم Firebase أو تهيئة خدمة إرسال بديلة عبر SMTP/موفر بريد قبل إعادة المحاولة.
