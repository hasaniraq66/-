# تفعيل PWA — ديوني وميزانيتي برو

تم تجهيز التطبيق كتطبيق ويب تقدّمي قابل للتثبيت بعنوان عربي واتجاه RTL، مع تعريف مستقل، أيقونة متجهة صغيرة، ولون واجهة متوافق مع الهوية المالية الداكنة.

يتولى عامل الخدمة تخزين ملفات الواجهة المولدة ذات الأسماء الموقعة فقط، ويوفر صفحة عربية عند انقطاع الاتصال. لا تُخزَّن مسارات `/api/` أو أدوات التطوير مؤقتاً، لذلك لا تُخزَّن استجابات مصادقة أو بيانات مالية حساسة عبر عامل الخدمة. يبقى تخزين Firestore المحلي المتعدد التبويبات مسؤولاً عن البيانات التي سبق للتطبيق تحميلها.

أضيفت رسائل واضحة للحالة غير المتصلة، ولجاهزية العمل دون اتصال، ولتحديث التطبيق، مع زر تثبيت يظهر عندما يدعم المتصفح حدث التثبيت. ظهر نموذج الدخول سليماً على 1280×720 و375×812 بعد التهيئة.

تحقق بناء Vite من توليد `manifest.webmanifest` و`sw.js` و`workbox`، واجتازت 113 اختباراً وفحص TypeScript. يحتاج المستخدم إلى فتح النسخة المنشورة عبر HTTPS مرة واحدة حتى يسجل المتصفح عامل الخدمة ويعرض خيار التثبيت حسب سياسة المتصفح.

## التحقق الفعلي في معاينة الإنتاج

شُغلت معاينة إنتاج HTTPS من ملفات `dist`، ثم أعيد تحميلها دون أي تسجيل يدوي. سجل المتصفح عامل الخدمة تلقائياً بحالة `activated`، وظهر زر «تثبيت» من حدث `beforeinstallprompt`.

بعد أن أصبح عامل الخدمة متحكماً بالصفحة، أُوقف خادم المعاينة ثم فُتح مسار جديد غير مخزن. ظهرت صفحة `offline.html` العربية مع زر «إعادة المحاولة» بدلاً من خطأ الشبكة، مما يؤكد عمل مسار عدم الاتصال الفعلي.

مسار النشر المعتمد على Vercel هو `pnpm build:vercel`، وقد اكتمل بنجاح ضمن ذاكرة Node مضبوطة، مولداً `manifest.webmanifest` و`sw.js` وملف Workbox. لا يعتمد النشر على أمر `pnpm build` الشامل لأنه يضيف حزمة الخادم المحلية، بينما تكامل Vercel في هذا المشروع يعتمد بناء الواجهة المخصص للنشر.
